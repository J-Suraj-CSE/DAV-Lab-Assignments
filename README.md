# DAV LAB

This repository contains the laboratory experiments for Data Analysis and Visualization (DAV).

## Folder Structure

- `code/`: Contains all Jupyter Notebook experiments (`Exp1.ipynb` to `Exp5c.ipynb`) as well as any output files they generate (e.g., `processed_text.csv`, `filtered_data.csv`).
- `datasets/`: Contains the input datasets used in the experiments (`diabetes.csv`, `AirPassengers.csv`, `data.csv`, `data.xlsx`).

## Setup

1. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Navigate to the `code/` directory and start Jupyter Lab or Jupyter Notebook:
   ```bash
   cd code
   jupyter lab
   ```

## Experiments Overview
- **Exp1**: Introduction to numerical computation and data visualization.
- **Exp2**: Data manipulation, importing/exporting, and cleaning.
- **Exp3**: Basic machine learning modeling (Linear and Logistic Regression).
- **Exp4**: Statistical hypothesis testing (Z-test, ANOVA).
- **Exp5**: Regression model evaluation and Time series analysis.
